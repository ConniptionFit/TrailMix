## 1. Hard rules for the test session

- **Never uninstall, clear data for, or `pm clear` `com.trailmix.app`** (the real app). `allowBackup=false`: it destroys every real note. A signature error on the real app means the wrong key; fix the key.
- **Only `com.trailmix.app.preview` may be uninstalled**, and only through `scripts/device-test.sh replace-preview` (it refuses any other package).
- **The real app is only updated in Phase G**, only with a release-key build made on the workstation (`scripts/device-test.sh install`, which refuses a wrong signer or a network permission), and only after the user says go.
- **Never point TrailMix Preview's Export location at the real app's export folder.** Use a new folder such as `Documents/TrailMix-Preview`, or the two apps will overwrite each other's Markdown files.
- **Never bypass the phone's lock.** If it locks or USB drops, ask the user to unlock or reconnect and note what was interrupted.
- **The user may be using the phone.** Screenshot before tapping; move PiP windows aside and back.
- **Do not delete or edit the user's existing notes in the real app.** All capture tests run in TrailMix Preview.
- **Confirm before any destructive or outward action** (merging the PR, publishing a release, pushing to `main` or Forgejo).
- Record evidence for every case: screenshot and/or UI dump plus the logcat file, under `Android/test-artifacts/` (gitignored).

## 2. Phase A: Pre-flight and install (about 20 min)

Run everything from the workstation clone (`~/Projects/trailmix-android`), with `JAVA_HOME` and `ANDROID_HOME` set as in CLAUDE.md's Build row. `gh` must be logged in (`gh auth status`) to the account that can read the private repo.

1. **Get the branch:** `git fetch origin && git checkout claude/compassionate-feynman-34pau4 && git pull --ff-only`. Confirm a clean tree and note `git rev-parse --short HEAD`.
2. **CI must be green on that HEAD:** `gh pr checks 18 --repo ConniptionFit/TrailMix`. Both `test` (full `./gradlew check`) and `preview` must pass. If `test` is red, fix it first (retry once only for the known `lintAnalyze*` K2 flake in CLAUDE.md). If `preview` is still running, wait.
3. **Confirm the pre-release matches HEAD:** `gh release view v1.22.0-preview --repo ConniptionFit/TrailMix`. The title's short SHA must equal step 1's. If not, the preview run for HEAD hasn't finished or failed: `gh run list --repo ConniptionFit/TrailMix --workflow "Preview APK" --branch claude/compassionate-feynman-34pau4 --limit 3`.
4. **Local gate:** `cd Android && ./gradlew check`. Must pass.
5. **Device preflight:** `scripts/device-test.sh preflight`. Record the real app's version (expect 1.21.0 / 25) and signer (must equal `b6a53a16…3ae5bbd`), whether a preview is already installed, the granted permissions and the lock state. Ask the user to unlock if needed.
6. **Install the preview:** `scripts/device-test.sh install-preview`. It downloads the APK into `Android/test-artifacts/`, shows the release notes, refuses a wrong package or a network permission, and runs `adb install -r`. On `INSTALL_FAILED_UPDATE_INCOMPATIBLE` (an older preview from a different CI key), run `scripts/device-test.sh replace-preview`. Expect versionName **1.22.0-preview**, versionCode 26.
7. **First-run setup of TrailMix Preview** (fresh app, no notes): launch **TrailMix Preview** from the launcher (not TrailMix). Grant the microphone and notification permissions when asked. In Settings, set the Export location to a **new** folder, `Documents/TrailMix-Preview` (never the real export folder). Leave Speech recognition language at its default.
8. **Real app untouched:** `TM_PKG=com.trailmix.app scripts/device-test.sh preflight` still shows v1.21.0 with an unchanged `lastUpdateTime`. Open the real **TrailMix** once: notes still present. `scripts/device-test.sh crashes` is empty.

**Stop condition:** anything that changes the real app, or a crash on first launch of Preview. Stop, capture everything, and report to the user before continuing.

## 9. Triage and fixing

- **Severity:** S1 = data loss, crash, merge stuck/unusable, wrong user data → fix before merge. S2 = feature visibly wrong (anchor dropped, Next Steps malformed, wrong template applied, labels mostly wrong) → fix in this session if small, otherwise file. S3 = quality/tuning (heading wording, Me/Them accuracy 60-80%, chip cosmetics) → file a To-Do row.
- **Fix loop:** reproduce → smallest fix → pure unit test where a seam exists → `./gradlew check` → build and install a **local** preview → re-run the failing case and its neighbours → commit (`<ID>: ...`) → push → both CI workflows green → `install-preview` the new CI build before the final re-check.
  - Local preview build: `cd Android && ./gradlew :app:assemblePreview && $ANDROID_HOME/platform-tools/adb install -r app/build/outputs/apk/preview/app-preview.apk`. The workstation's debug key differs from CI's, so the **first** local install over a CI preview fails with `INSTALL_FAILED_UPDATE_INCOMPATIBLE`. Then run `$ANDROID_HOME/platform-tools/adb uninstall com.trailmix.app.preview` (**the `.preview` package only, never `com.trailmix.app`**), install, and redo Phase A step 7 setup. Later local builds update in place.
  - Never "fix" a failure by installing a debug or preview build over `com.trailmix.app`.
- Model-quality issues (Nano ignoring an instruction) belong in post-processing (`NoteShape`, `AnchorCoverage`, `StructuredSummaryPrompt`), not longer prompts. The structuring prompt's overhead cap test is 3,900 chars.
