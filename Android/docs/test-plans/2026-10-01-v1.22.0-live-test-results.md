**Run:** 2026-10-01, Pixel 9 Pro (Gemini Nano via AICore), TrailMix Preview (`com.trailmix.app.preview`), plan: [`2026-10-02-v1.22.0-live-test.md`](2026-10-02-v1.22.0-live-test.md).

**Evidence:** `Android/test-artifacts/<case>/` (gitignored: screenshots, note dumps, FGS samples, logs).
**Speech:** scripts rendered with Piper TTS (en_US-lessac-medium, en_US-ryan-high) and played from the workstation speakers into the phone mic. TTS has no natural pauses, so Gemini's ASR returned each script as one long transcript line (all bullets in a note share one `mm:ss`); the C8 audio has 2.5 s gaps.

## Headline

**One S1 and two S2 defects (and a cosmetic one) were found by the device and fixed; none were visible to unit tests, lint, ktlint or CI.**

| ID | Sev | What | Why nothing caught it |
|---|---|---|---|
| **REL-23** | S1 | `AutoTemplate`'s 1:1 regex (`1\s*[:\-]\s*1(?![\d:])`) throws `PatternSyntaxException: Incorrect Unicode property` on Android, so **every End & Merge with the Auto template (the v1.22.0 default) failed**. The failure was swallowed by `getOrElse { -1L }`: the capture ended, no note appeared, no message. The REL-09 journal kept the transcript, so nothing was lost. | Android's `java.util.regex` is ICU-backed: a set opening `[:` is read as a POSIX class and ICU scans ahead for a closing `:]` (here the one in the lookahead). The host JVM accepts the pattern. |
| **AI-23** | S2 | ML Kit's prompt API caps a reply at **256 tokens** (`maxOutputTokens must be between 1 and 256`). The structured-summary JSON for a Granola-shaped note needs more, so Gemini Nano's reply was cut off mid-key (also fenced, also with sections nested inside a stray `{"sections": [...]}`, also with the `sections` array left unclosed). The strict parse threw and the note silently became the deterministic fallback: verbatim sentences, no model bullets, **no Next Steps**. | Unit tests never run the model. |
| **AI-24** | S3 | Next Steps rendered twice (a model-made "Next Steps" topic section plus the dedicated list) and repeated the owner (`Chloe: Chloe to provide ...`). | Same. |
| **AI-28** | S2 | The structuring reply is capped at 256 tokens, so one call covers only a few minutes of dense speech: a 13-minute session's note (C8) was built from its first ~1.5 minutes and the rest was silently dropped, defeating AI-05's whole-session coverage. A second device-only cause: AICore answers `BUSY` (code 9) to a call that arrives while it is still closing the previous session, which rejected the follow-up and parts 2 and 3 within 43 ms of a successful part 1. | Same: unit tests never run the model, and BUSY is timing on the device. |

Fixes, all on the branch with unit tests where a seam exists:

| Commit | Change |
|---|---|
| `bee48e0` REL-23 | Colon moved off the set's first position in `AutoTemplate`, `NoteShape`, `NoteTitle` (`[\-:]`); new `IcuRegexSafetyTest` fails if any main source reopens a set with `[:` (confirmed it fails on the original regex); the three merge catch sites now `Log.e` instead of swallowing silently. |
| `1b5c50f` AI-23 | New pure `StructuredJson`: `repair()` cuts a truncated reply back to its last complete element and closes what is open; `sectionObjects()` finds sections wherever they sit; if the reply was truncated before `actionItems`, one small follow-up call asks for the action items alone (new `StructuredSummaryPrompt.buildActionItems`); cue-based extractor is the last resort. A failed structuring step logs its exception type only (a `JSONException` message can embed the model reply, i.e. transcript content). |
| `22f7b92` AI-23 | `harvest()`: when even the repaired text is not JSON, keep every complete section / action-item object wherever it sits (second real failing reply is a test fixture). |
| `3479c48` AI-24 | `NoteShape` drops a model-made Next Steps/Action Items section when real action items exist; `ActionItem.displayText()` drops an owner the action restates. |
| `ce64e79` AI-23 | Requested JSON shortened (no per-bullet `[mm:ss]`, no `"details": null`) so more of it fits the cap. C5 before: 3 of 5 template sections, the $20,000 budget lost; after: all 5, budget kept. |
| `5abda27` AI-28 | New pure `StructuredParts` (split into parts of at most 900 characters on line boundaries, merge same-heading sections, drop repeated actions); `generateStructuredSummary` structures each part with its own call (typed notes to part 1, a `part N of M` line later, a failed part skipped), runs the small action-items follow-up per truncated part, then merges and applies `AnchorCoverage` / `TemplateSectioner` / `NoteShape` as before; progress counts the parts. New pure `retryWhile` wraps every model call: retry up to 4 times, 2 s growing, on `GenAiException` BUSY only (cancellation is never retried). Part and follow-up failures log the exception type and ML Kit's integer code, never the message. |

**495 unit tests (debug) / 490 (release), 0 failures; `./gradlew check` green (the known `lintAnalyze*` K2 flake needed a retry once); CI green on the pushed heads.**
