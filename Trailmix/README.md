# Trailmix vault pack

This folder is the **Obsidian vault documentation** for TrailMix, written to match the house style of the sibling `Powarr/` vault notes.

## Install into your Obsidian vault

Copy or symlink this directory to:

```text
<YourVault>/Trailmix/
```

so it sits next to `Powarr/`. Wiki links (`[[Master Prompt]]`, etc.) resolve inside the folder.

| Note | Role |
|---|---|
| [[TrailMix Overview]] | Landing page |
| [[Master Prompt]] | Agent context (mirrored as repo `/CLAUDE.md`) |
| [[Future Improvements]] | Living roadmap |
| [[Architecture]] … [[Troubleshooting]] | Module deep-dives |

After copying, open [[TrailMix Overview]] from the vault graph or quick switcher.
